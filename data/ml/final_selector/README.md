# Final selector results

These files are generated by `scripts/finalize_ml_selector.py` from the current
**100-graph** common ML table. The raw QAOA CSVs are not read or modified by
the finalization script.

## Frozen protocol

- Split: 70 train / 15 validation / 15 test graphs (seed 2027).
- Target: mean expected approximation ratio over two run seeds.
- Budgets: B256 and B512 are maximum shots-per-circuit feasibility limits.
- Model choice: lowest mean selection regret on validation only.
- Fixed baseline: best feasible configuration for each noise/budget pair on training graphs only.
- Inference: graph-level test evaluation with graph-clustered uncertainty/statistics.

The current model selected on validation is **ExtraTrees** with the full
pre-execution structural feature set.

## Current frozen test result

The current test evaluation contains 90 graph/noise/budget cases:

```text
15 test graphs × 3 noise conditions × 2 budgets = 90 cases
```

| Method | Mean expected approximation ratio |
|---|---:|
| Uniform-random expectation | 0.694513 |
| Training-only fixed baseline | 0.707455 |
| ML selector (ExtraTrees) | 0.711856 |
| Feasible oracle | 0.730775 |

The ML selector improves on the training-only fixed baseline by **0.004401
absolute (0.622148% relative)**. Mean feasible-oracle regret is 0.018918,
exact oracle-selection accuracy is 22.2222%, and top-3 oracle coverage is
61.1111%.

These are descriptive empirical results on the held-out 15-graph test set and
should not be interpreted as universal performance guarantees.

## Validation and test policy

Model family and feature-set decisions are made on the validation partition
only. After freezing those choices, the final model is refit on train +
validation and the test partition is evaluated once. Test outcomes are never
used to revise the selector.

## Historical provenance

The repository previously contained an 89-graph noisy snapshot with a 62/13/14
split. Those artifacts are retained for provenance, but they are **not** the
primary paper results. The current 100-graph snapshot supersedes that analysis.

## Files

- `analysis_manifest.json`: frozen inputs, choices, and headline metrics.
- `validation_model_comparison.csv`: validation-only model selection.
- `validation_feature_ablations.csv`: graph/noise feature ablations.
- `validation_permutation_importance.csv`: selector-aware interpretability.
- `fixed_baseline_choices.csv`: training-only fixed choices.
- `test_selected_configurations.csv`: paired case-level test decisions.
- `test_summary.csv`: overall, budget, noise, and budget-by-noise summaries.
- `test_graph_clustered_statistics.csv`: graph-level uncertainty and tests.
- `test_method_comparison.svg`: paper-ready method comparison.
- `validation_permutation_importance.svg`: paper-ready importance plot.
