# Final selector results

These files are generated by `scripts/finalize_ml_selector.py` from the frozen
89-graph common ML table. The raw QAOA CSVs are not read or modified.

## Frozen protocol

- Split: 62 train / 13 validation / 14 test graphs (seed 2027).
- Target: mean expected approximation ratio over two run seeds.
- Budgets: B256 and B512 are maximum shots-per-circuit feasibility limits.
- Model choice: lowest mean selection regret on validation only.
- Fixed baseline: best configuration for each noise/budget pair on training
  graphs only.
- Inference: paired bootstrap and exact sign-flip tests clustered by graph.

ExtraTrees was selected on validation data with mean regret 0.020307. The
validation ablation increased regret from 0.020307 to 0.025758 when graph
structure was removed, supporting retention of the graph features.

## Frozen test result

Across 84 graph/noise/budget cases:

| Method | Mean expected approximation ratio |
|---|---:|
| Uniform-random expectation | 0.689134 |
| Training-only fixed baseline | 0.700960 |
| ML selector | 0.702228 |
| Feasible oracle | 0.724351 |

The ML selector improves on the stronger fixed baseline by 0.001269 absolute
(0.181% relative). Mean feasible-oracle regret is 0.022123, exact oracle
selection accuracy is 17.86%, and top-3 oracle coverage is 58.33%.

The overall graph-clustered 95% bootstrap interval for ML minus fixed is
[-0.008654, 0.010803], and the exact two-sided sign-flip p-value is 0.8098.
The observed improvement is therefore descriptive, not statistically
significant with 14 test graphs. Performance is also budget-dependent: ML is
0.247% below fixed at B256 and 0.607% above fixed at B512.

These resource-aware numbers should not be conflated with the repository's
earlier unconstrained prototype comparison against one global C06 baseline;
that result answers a different, easier comparison and is retained for
historical reproduction.

## Files

- `analysis_manifest.json`: frozen inputs, choices, and headline metrics.
- `validation_model_comparison.csv`: validation-only model selection.
- `validation_feature_ablations.csv`: graph/noise feature ablations.
- `validation_permutation_importance.csv`: selector-aware interpretability.
- `fixed_baseline_choices.csv`: training-only fixed choices.
- `test_selected_configurations.csv`: paired case-level test decisions.
- `test_summary.csv`: overall, budget, noise, and budget-by-noise summaries.
- `test_graph_clustered_statistics.csv`: graph-level uncertainty and tests.
- `test_method_comparison.png`: paper-ready method comparison.
- `validation_permutation_importance.png`: paper-ready importance plot.
